## Deskripsi Proyek
ADI SPORT SHOES STATION merupakan website katalog sepatu olahraga yang menampilkan berbagai pilihan produk beserta informasi merek, harga, ukuran, jenis olahraga, dan gambar produk.

## Fitur Website
- Menampilkan katalog sepatu olahraga.
- Menampilkan gambar dan informasi produk.
- Menampilkan halaman detail produk.
- Navigasi antarhalaman.
- Tampilan website menggunakan Bootstrap.

## Teknologi yang Digunakan
- PHP
- Laravel
- MySQL
- HTML dan CSS
- Bootstrap

## Cara Menjalankan Proyek
1. Clone repository ini.
2. Jalankan `composer install`.
3. Salin `.env.example` menjadi `.env`.
4. Buat database MySQL dan sesuaikan konfigurasi database pada `.env`.
5. Jalankan `php artisan key:generate`.
6. Jalankan migrasi dan seeder menggunakan `php artisan migrate --seed`.
7. Jalankan `php artisan serve`.
8. Buka alamat lokal yang ditampilkan di terminal.
